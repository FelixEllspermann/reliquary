RELIQUARY — Progression Screens (Einzeldateien)
1920 x 1080

Diese vier Dateien einfach doppelklicken. Jede ist komplett in sich
geschlossen, es wird nichts nachgeladen, kein Server noetig.

  Profile Screen.html    Duelist Record - Identitaet, Statistik, Match History, Seals
  Rank Ladder.html       Die zehn Seals mit je fuenf Unterraengen
  Leaderboard.html       Top 50, Season und All Time
  Cosmetics Shop.html    20 Cosmetics + Glossy / Rainbow / Static

Beim ersten Oeffnen erscheint kurz ein Rauten-Symbol, waehrend die
Datei sich selbst auspackt.

Interaktiv:
  Profile Screen    Tabs oben rechts, Titel-Chip unter dem Namen aufklappbar
  Rank Ladder       Klick auf einen Rang zeigt rechts seine fuenf Unterraenge
  Leaderboard       Season 3 / All Time oben umschaltbar
  Cosmetics Shop    Klick auf ein Item, Tab "Card Finishes" fuer die drei Effekte

Die bearbeitbaren Quellen liegen eine Ebene hoeher als .dc.html.
