# 目的
二人のデュエリスト、二つの金庫、一つのテーブル。相手のライフポイントが0になった瞬間 — あるいは相手が空のデッキからドローしなければならないのにできなくなった瞬間 — 勝利だ。この本の残りはすべて、そこへたどり着く方法について：使うマナ、召喚するモンスター、応じる魔法、そして勝負を封印する聖遺物。

こういうカードゲームが初めてなら、まずテーブル、自分のターン、バトルを読もう。残りは必要になってからで遅くない。

[img:board|テーブルの下側が自分の陣地、上側が相手の陣地。]

# テーブル
デュエリストごとにモンスターゾーン5つが一列に並び、セットした魔法のための魔法ゾーン3つ、アーティファクトゾーン2つ、デッキ、墓地、除外の山、エクストラデッキがある。自分の手札は画面の下に広がり、相手の手札は裏向きで上に見える。プレイヤーカード — 自分の英雄 — は自分の列の左に、ライフポイントとマナは右のプレートにある。

[img:plate|上がライフポイント、下がマナ。変わるたびに動く。]

ライフポイント：8000から始まる（英雄によって多少違う）。ダメージ — 戦闘でも効果でも — が削り、回復が戻す。上限はない。

マナ：自分のターンが始まるたびに補充される。最初のターンは3、その後ターンごとに1ずつ増えて最大10。使わなかったマナは、カードが別に言わない限りターン終了時に消える。マナは魔法、INFUSED効果、英雄効果、聖遺物召喚の代金だ — モンスターの通常の効果はタダで使える。

手札枚数の制限：8枚。自分ターン終了時にそれより多ければ、8枚になるまで捨てる。

[img:phases|フェイズバー。光っている段階が、いまデュエルがいる場所だ。]

# 自分のターン
ターンは常にこの順で五つのフェイズを進む：

- DRAW PHASE — カードを1枚ドローする。先攻は最初のターンだけこれを飛ばす（先攻は5枚、後攻は6枚で始まる）。
- STANDBY PHASE — 「自分のStandby Phaseの間」の効果がいま起きる。通行料や維持費はここで払う。
- MAIN PHASE — ターンの心臓部。モンスターを召喚またはセットし、魔法とアーティファクトをプレイし、起動効果を発動し、表示形式を変え、聖遺物を召喚する。順番は自由、マナとルールの許す限り。
- BATTLE PHASE — 表側攻撃表示のモンスターで攻撃する。先攻は最初のターンにBattle Phaseがない。
- END PHASE — 「自分のEnd Phaseの間」の効果、手札枚数の制限、そしてターンが渡る。

Main PhaseもBattle Phaseもフェイズボタンで好きな時に終えられる。ゲームが攻撃を強いることはない。

[img:hand|自分の手札。いまプレイできるカードは明るく光る。テーブルへドラッグするか、クリックして選択肢を見よう。]

# カード
カードは四つの種類のどれかに属する — それに英雄がいる。

モンスターはレベル（1～3）、属性（炎、水、風、地、光、闇）、タイプ（ドラゴン、人間、獣、機械、天使、悪魔、神話、動物…）、そしてATK／DEFを持つ。戦い、守り、たいていは効果がある。

魔法はマナを払って手札からプレイし、その後墓地へ行く。通常魔法は自分のMain Phaseに。速攻魔法はレスポンスとしても使える — 相手ターンに、チェーンの途中に、攻撃が宣言された時に。どの魔法も裏側でセットしておいて後で使える。

アーティファクトはテーブルに残る。モンスターに装着されるもの（装着者にATK／DEFと効果）、フィールドアーティファクト、プレイヤーの枠に置かれるものがある。アーティファクトゾーンは2つ、セットした魔法は魔法ゾーン3つで待つ。

[img:artifacts|アーティファクトゾーンのプレイヤーアーティファクト2枚。何かが取り除くまで残り続ける。]

聖遺物はエクストラデッキに住む。各カードには盤面条件——満ちた墓地、3体のモンスター、追い詰められた英雄——とマナの代価が記されている。条件を満たせばメインフェイズに呼び出せる。生け贄も供物も不要、盤面そのものが鍵だ。

インカーネイトはエクストラデッキの赤いカード。それぞれ独自のレベルを持つ。レベル合計がちょうどそのレベルになるモンスターを生け贄に捧げよ——うち1体はカードに記された器であること。インカーネイトは無償で降臨し、次の自分のスタンバイフェイズにエクストラデッキへ帰る。あるいは儀式——生け贄を指名する赤い魔法——で永遠に縛り付けよ。

プレイヤーカードは自分の英雄だ。開始ライフポイントを定め、英雄効果をくれる：マナ2、1ターンに1度、いつでも使える。英雄は攻撃も破壊もされない。

[img:card|モンスターの解剖図：上に名前とレベルの紋章、絵の下に属性とタイプ、下にATKとDEF、テキスト欄に効果。]

[img:effectbox|デュエル中に任意のカードをクリックすると、左の詳細パネルがそのカードの効果を並べる — コストの印から、いつ発動するかまで。]

# 召喚
通常召喚 — 1ターンに1度、手札から、自分のMain Phaseに。レベル1はタダで出てくる。レベル2は生贄1体、レベル3は2体が必要：その数だけ自分のモンスターを先に墓地へ送る。表側で召喚する代わりに、モンスターを裏側守備表示でセットすることもできる — これも通常召喚の回数を使う。

特殊召喚 — 通常召喚でないすべての召喚。カードがやってくれる：「自分の墓地からモンスター1体を特殊召喚する」、「…ならこのカードを手札から特殊召喚できる」。特殊召喚は通常召喚の回数を使わず、ターンごとの制限もない — ただし、各カード名の「特殊召喚できる」という自身の条件は1ターンに1度しか使えない。

聖遺物召喚——エクストラデッキから、メインフェイズに、記された盤面条件を満たせば行える。マナを払い、ゾーンを選ぶ——代価は盤面だけだ。

インカーネイト召喚——供物：レベル合計がちょうどインカーネイトのレベルになる生け贄を選ぶ（1体は器であること）。マナ不要だが、次の自分のスタンバイフェイズまで。儀式版は赤い魔法：指名されたモンスターを捧げれば、指名されたインカーネイトは永遠に残る。

召喚されたすべてのモンスターはゾーンと表示形式を受け取る。表側攻撃表示はATKで戦い、守備表示はDEFで持ちこたえてダメージを与えない。裏側表示モンスターは常に守備表示だ。めくられるまで、誰にも正体は分からない。

[img:zones-attack|攻撃表示のモンスター二体と、セットされたモンスター一体：裏側表示、見えるのはカードの裏だけ。]

[img:zones-defense|守備表示は横向きに寝る — DEFが攻撃者を迎え撃つ。]

# バトル
自分のBattle Phaseに、表側攻撃表示のモンスターはそれぞれ1回攻撃できる。モンスターをクリックし、続けて目標をクリックする — あるいは相手の英雄をクリックして直接攻撃する。直接攻撃は相手がモンスターをコントロールしていない間だけ可能だ。召喚されたターンでも、カードが別に言わない限り普通に攻撃できる。

- 攻撃表示対攻撃表示：高いATKが勝ち、負けた方は破壊され、その差分を負けた側のコントローラーがダメージとして受ける。ATKが同じなら：両方破壊、ダメージはなし。
- 守備表示への攻撃：自分のATK対相手のDEF。ATKが高ければ守備側は破壊される — ダメージなし。ATKが低ければ：自分のモンスターは生き残るが、その差分を自分が受ける。同じなら：何も起きない。
- 裏側表示モンスターを攻撃すると、まず表側になる。リバース効果があればその時発動する。
- 直接攻撃：ATK全部がダメージ。

表示形式はモンスターごとに1ターンに1度、自分のMain Phaseに変えられる — ただし召喚されたターンと攻撃した後は不可。裏側表示モンスターを表側攻撃表示にめくるのも、そのモンスターの表示形式変更として数える。

# 効果
カードのテキストが、効果がいつ起きて何がかかるかを教えてくれる。言葉は常に同じなので、一度だけ覚えればいい：

- 召喚時 — このカードが召喚された時。勝手に発動し、対象は自分で選ぶ。
- 起動 — 自分のMain Phaseに自分から発動する（「1ターンに1度：…」）。
- 速攻 — レスポンスウィンドウが開いていればいつでも、相手ターンでも発動できる。
- 永続 — カードがフィールドに表側である間、常に効いている。発動もコストもない。
- STANDBY／END PHASE — 自分のターンのそのフェイズに起きる。
- リバース — 裏側表示カードが表側になった時。自分でめくっても、攻撃されても。
- 手札／墓地 — 手札や墓地から使う効果もある。山の中の何かが動ける時、山が光る。山をクリックしよう。
- 1ターンに1度 — 文字どおり。カード名につき1ターンに1度のものもある。

コストが先、効果が後だ：「マナ2を払う：カードを1枚ドローする」は、ドローが無効にされてもマナは消えたという意味。効果がいままったく処理できないなら — 適正な対象がない、召喚する空きゾーンがない — そもそも発動できない。

[img:activation|効果が発動すると、カードとテキストが一歩前に出て、両デュエリストに何が起きているか読ませてくれる。]

# INFUSED効果
多くのカードがINFUSED効果を載せている：常にマナのかかる強化版だ。二つの味がある：

- 連結型（「その代わりにマナ2を払う：…」）はすぐ上の効果を強化する。1ターンには通常版かINFUSED版のどちらか一方、両方は使えない。
- 独立型は別個の、それ自体の能力だ。カードの他のすべてと一緒に動く。

カードを読む時はマナの印を見よう：数字付きの青 = その分かかる、緑のマナ不要 = タダ。

[img:cardtext|カードテキストのパネルがすべてを解きほぐす：コストの印、効果の名前、発動のタイミング、1ターンに1度かどうか。]

# チェーンとレスポンス
カードが発動されるたび、モンスターが召喚されるたび、攻撃が宣言されるたびに、相手にレスポンスウィンドウが生まれる — 相手が動けば自分にも生まれる。速攻効果で応じるとチェーンが積み上がる：リンク1、リンク2、リンク3… 誰もリンクを足さなくなったら、チェーンは後ろから、最後のリンクから処理される。

二つ目の効果が最初のものに応じると、画面の上からチェーン表示が降りてきてリンクを順に並べる — 自分のものは青緑、相手のものは赤。リンクが積まれている間はチェーン構築中、発動している間は処理中 — 最後のものから。

チェーンの処理中は何も新たに発動できない — 普段なら発動するはずの効果もだ。チェーンが終わるのを待ち、その後で発動する。無効になったカードは紫のNEGの印を付け、ターン終了時までその効果は何もしない。それでも何かしようとすれば、ゲームが知らせてそのまま進む。

[img:log|右のデュエルログはすべての発動、支払い、結果を順に収める。迷ったら読み返そう。]

左下のリアクション切替は自動の提案を切る：相手の行動が自分のせいで止まらなくなり、自分自身のトリガーだけが尋ねてくる。手札に応じ手がない時に便利だ。

[img:reactions|リアクション・オン：ゲームが止まってレスポンスを提案してくれる。オフ：自分のトリガーだけが尋ねる。]

# 山
墓地 — 破壊されたカード、使ったカード、捨てたカードの行き先。ここからカードを蘇らせたり、中身を数えたりする効果が多い。山をクリックすれば中を調べられる。

除外の山 — 第二の墓地。除外されたカードは、特別に戻すカードがない限りデュエルの外だ。これを数える聖遺物もある。

デッキ — 裏向きにシャッフルされている。「サーチ」効果はデッキからカードを見つけ出し、「削る」は一番上のカードを墓地へ送る。デッキが尽きること自体は何でもない — ドローしなければならないのにできないことが敗北だ。

エクストラデッキ — 自分の聖遺物たち、最大20枚。ドローされることはない。それぞれが条件を待っている。

[img:piles|デッキ、墓地、除外の山、エクストラデッキは自分の陣地の縁にある。数字が中身の枚数を示す。]

# デッキ工房
デッキは40～80枚、同じカードは最大3枚、それに英雄1枚とエクストラデッキの聖遺物最大20枚。バンリストが特定のカードの枚数をさらに減らすことがある — 制限数はタイルに表示され、保存時に適用される。

持っているカードでしか組めない。カードごとに四つの仕上げ — ノーマル、光沢、レインボー、スタティック — があり、デッキに入れた1枚の仕上げがテーブルに出る。引き当てられないカードは砂で生成できる。余った1枚を分解すれば砂が返ってくる。

[img:deckbuilder|デッキパネル：名前、英雄、40～80基準の枚数、そして封じ込めた1枚1枚。]

[img:deckbalance|デッキバランスはレベル1、2、3のモンスターが何枚ずつかを示し — デッキが規定に合っているかを教えてくれる。]

# どこで遊ぶか
- ソロ — あらゆる気性のボットたち。デッキに慣れるのに良い。
- プレイ — コインとランクを懸けたオンラインの待機列、コードで開くプライベートロビー、そしてライブのデュエルを見る観戦。
- チャレンジ — 塔：十五の階、十五の守護者、階ごとの初勝利にパック。
- ドラフト — 新しいカードプールからデッキを組み、引き当てたもので登る。
- ショップ — パック、英雄の隠し場、着せ替え。統計は何が勝っているかを見せてくれる。

オンラインの勝利、敗北、引き分けはすべてコインをくれる。ランクポイントは五段階ずつの封印十個を上下させる。シーズンは一か月だ。

# 最後に一つ
カードのテキストはこの本より偉い。カードがルールにないことを言うなら、カードが正しい — 金庫は例外だらけで、隣の用語集がカードの使うすべての言葉を説明してくれる。
