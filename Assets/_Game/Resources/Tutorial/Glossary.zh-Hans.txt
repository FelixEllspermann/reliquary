发动 (Activate) :: 使用法术、神器或效果。费用在发动时支付；效果随后处理——若有人回应，则作为连锁处理。
系列 (Archetype) :: 协同作战的卡片家族，通常共享名称前缀（“缚潮”“狱魔”）。提及某系列的辅助卡也属于该系列。卡组编辑器可以按系列筛选。
神器 (Artifact) :: 留在场上的卡。怪兽神器装备给一只怪兽（为装备者提供攻守加成和效果），场地神器影响整张桌子，玩家神器安放在你的英雄上。每位决斗者有两个神器区域。
攻击力 (ATK) :: 攻击数值。怪兽以攻击表示进攻或被攻击时使用。会被效果临时（“直到本回合结束”）或永久地修改。
攻击表示 (Attack Position) :: 竖置的表侧怪兽。它可以攻击，以攻击力作战；战斗落败时，其控制者受到差值伤害。
属性 (Attribute) :: 怪兽的元素：火、水、风、地、光、暗。部分效果和召唤条件会要求属性。
放逐 (Banish) :: 把卡移入放逐区——第二个墓地。被放逐的卡脱离决斗，除非有卡把它带回来。
放逐区 (Banishment) :: 被放逐卡的区域。有些效果能取回它们，有些圣物会清点它们。
禁限表 (Banlist) :: 限制每副卡组只能放2张、1张或0张的卡片列表。保存卡组时生效；限制会印在卡组编辑器的卡片上。
战斗伤害 (Battle damage) :: 战斗造成的伤害：攻击力差值，或直接攻击的全额攻击力。与效果伤害不同——有些卡只防其中一种。
战斗阶段 (Battle Phase) :: 回合的第四阶段。每只表侧攻击表示怪兽可以攻击一次。先攻方在其第一个回合没有战斗阶段。
表示形式 (Battle position) :: 攻击或守备。每只怪兽每回合在主要阶段可改变一次——召唤当回合不行，攻击后也不行。
弹回 (Bounce) :: “返回手牌”的俗称。被弹回的怪兽会失去它在场上获得的一切。
卡片种类 (Card type) :: 怪兽、法术、神器、圣物或玩家卡。有些效果会要求你宣言其中一种。
连锁 (Chain) :: 发动的堆叠。一个效果回应另一个时，它们组成连锁1、2、3……当无人继续追加时，连锁从最后一个开始倒序处理。连锁处理期间不能发动新的效果。
充能 (Charged) :: 慢燃机制：在本回合之前盖放的法术，可以在你的准备阶段触发更强的充能版本。
金币 (Coins) :: 决斗赚取的货币。用来买卡包和外观。
持续效果 (Continuous effect) :: 见“被动”。
控制权 (Control) :: 卡在谁的场上。有些效果会夺取怪兽的控制权；持有者不变，所以它离场时仍回到持有者的墓地或手牌。
费用 (Cost) :: 发动所支付的代价：法力、丢弃、祭献、放逐。即使效果之后被无效，费用也已支付。
指示物 (Counter) :: 效果放置在卡上的标记。死亡指示物显示为带数字的骷髅；卡片会说明堆满后会发生什么。
连动 (Coupled) :: 升级上一条效果的灌能效果（“改为支付2点法力：……”）。每回合只能使用普通版或连动版其中之一。
合成 (Craft) :: 用尘埃合成你缺少的卡。分解多余的卡可以拿回尘埃。
Deal :: 对手必须回应的交易：他选择选项A或B，卡片相应结算。两个选项永远对提出者有利。
死亡指示物 (Death counter) :: 在结束阶段累积的指示物；卡片达到其印刷的上限时被破坏。显示为带数字的骷髅。
卡组 (Deck) :: 你的主牌堆，40到80张，每张卡至多3份。洗切、背面朝上；从顶端抽卡。
守备表示 (Defense Position) :: 横置的怪兽。它不能攻击，以守备力抵挡，不造成战斗伤害。里侧的怪兽总是守备表示。
守备力 (DEF) :: 守备数值，怪兽以守备表示被攻击时使用。攻击方攻击力更低时，攻击方控制者受到差值伤害。
破坏 (Destroy) :: 通过战斗或效果把卡从场上送入墓地。“不会被破坏”只防这一种——不防放逐、弹回或祭献。
直接攻击 (Direct attack) :: 攻击对手的英雄而不是怪兽。只有对方不控制怪兽时才行。造成攻击者全额攻击力的伤害。
丢弃 (Discard) :: 把卡从手牌送入墓地。“随机”丢弃由运气决定，其余由丢弃方选择。
轮抽 (Draft) :: 从全新卡池组建卡组、用抽到的牌一路攀登的模式。
抽卡阶段 (Draw Phase) :: 回合的第一阶段：抽1张卡。先攻方的第一个回合跳过。
尘埃 (Dust) :: 分解卡片所得。用来合成卡片。
效果伤害 (Effect damage) :: 由卡片效果而非战斗造成的伤害（“造成800点伤害”）。有些卡只防其中一种。
结束阶段 (End Phase) :: 回合的最后阶段：“在你的结束阶段”的效果、手牌上限，然后回合交替。
装备 (Equip) :: 把怪兽神器附到一只怪兽（装备者）身上。装备者离场时，神器进入墓地。
Extra Deck :: 你的圣髑与降临体，最多20张。永远不会抽到；圣髑等待其盘面条件，降临体等待供奉或仪式。
里侧 (Face-down) :: 背面朝上打出的卡。里侧怪兽总是守备表示；里侧法术是盖放的，之后可以发动。
场上 (Field) :: 桌面：双方决斗者的所有区域。“在场上”指以表侧或里侧位于怪兽或神器区域。
场地神器 (Field Artifact) :: 放在神器区域、影响整张桌子而非单只怪兽的神器。
卡面工艺 (Finish) :: 一张卡的外观：普通、亮面、彩虹或静电。纯装饰；你放进卡组的那份的工艺就是上场的样子。
效果落空 (Fizzle) :: 效果处理时已无合法对象——目标离场、区域被占满。效果不做任何事；费用不退。
翻转 (Flip) :: 把里侧怪兽翻开——主动翻开（转为攻击表示）、被攻击翻开或被效果翻开。此时翻转效果触发。
墓地 (Graveyard) :: 被破坏、用过和丢弃的卡的去处。许多效果从这里带回卡片或清点其中的卡。点击牌堆可以翻看。
手牌 (Hand) :: 你持有的卡。你的回合结束时上限8张。
手牌上限 (Hand limit) :: 8张。结束阶段超过时，丢到只剩8张。
英雄 (Hero) :: 见“玩家卡”。
Hour Counter :: 倒计时标记。带时刻指示物的卡在其控制者的每个准备阶段失去1个；最后一个消失时，其倒计时效果发动。
起动效果 (Ignition effect) :: 你在自己的主要阶段主动发动的效果（“每回合一次：……”）。
幻影衍生物 (Illusion Token) :: 惑光系列放到对手场上的0/0衍生物。它占用区域，也能被破坏换取收益。
Incarnate :: 拥有自身等级的红色额外卡组怪兽。可通过供奉临时降临——祭品等级总和须恰好等于其等级，其中至少1只为容器——或通过其仪式永久降临。
灌能 (Infused) :: 卡上更强的效果，总是需要法力。分为连动（升级上一条效果）或独立（自成一体的能力）。
等级 (Level) :: 1、2或3，显示在纹章中。2级通常召唤需要1个祭献，3级需要2个。圣物是3级。
生命值 (Life Points) :: 你的生命。初始8000（部分英雄不同）。归0时决斗失败。
LP :: 生命值（Life Points）的缩写。
主要阶段 (Main Phase) :: 回合的第三阶段：召唤、打出法术和神器、发动起动效果、改变表示形式、召唤圣物。
法力 (Mana) :: 法术、灌能效果、英雄效果和圣物召唤的资源。每个你的回合补满：初始3点，每回合多1点，至多10点。未用完的法力会消失，除非卡片另有说明。
磨切 (Mill) :: 把卡组顶的卡送入墓地。可以是你自己的，也可以是对手的。
怪兽 (Monster) :: 作战的卡。等级、属性、种族、攻击力、守备力——通常还有效果。
怪兽神器 (Monster Artifact) :: 装备给单只怪兽的神器。
种族 (Monster Type) :: 龙、人类、野兽、机械、天使、恶魔、神话、动物……部分效果会在意它。
无效 (Negate) :: 关闭一张卡的效果。被无效的卡佩戴紫色NEG徽章直到回合结束；它试图行动时，什么都不会发生。
通常召唤 (Normal Summon) :: 在你的主要阶段从手牌打出怪兽，每回合一次。1级免费；2级需1个祭献，3级需2个。里侧盖放怪兽也消耗这次机会。
Offering :: 临时的降临体召唤：牺牲等级总和恰好等于降临体等级的怪兽（其中至少1只容器）。无需法力。降临体在你的下个准备阶段回到额外卡组。
每回合一次 (Once per turn) :: 该效果每回合可用一次。有些是“每回合一次、以卡名为准”——三张同名卡共享一次。
持有者 (Owner) :: 卡来自谁的卡组。即使控制权改变，卡仍会回到持有者的手牌、卡组或墓地。
被动 (Passive) :: 只要卡以表侧在场就持续生效的效果。无需发动、无费用、不占连锁。
阶段 (Phase) :: 回合五个步骤之一：抽卡、准备、主要、战斗、结束。
玩家卡 (Player Card) :: 你的英雄。决定你的初始生命值，并提供一个每回合一次、花费2点法力的英雄效果。不能被攻击或破坏。
表示切换 (Position change) :: 在攻击与守备之间切换怪兽。每只怪兽每回合一次，在你的主要阶段。
速攻法术 (Quick Spell) :: 可以作为回应发动的法术——在对手回合、连锁中、攻击宣言时。也可以在自己的主要阶段使用。
段位 (Rank) :: 十枚封印、各五个小段。排位决斗按段位分升降；赛季为一个月。
稀有度 (Rarity) :: 普通、精良、稀有或传说——决定开包掉率。与强度无关。
反应开关 (Reactions toggle) :: 决斗左下角的开关。关闭后，游戏不再询问你是否回应对手的行动；你自己的触发仍会询问。
圣物 (Reliquary) :: 来自额外卡组的头目怪兽。其召唤条件、法力价格和祭献都印在卡上。和普通怪兽一样占用怪兽区域。
圣物召唤 (Reliquary Summon) :: 条件达成后在你的主要阶段从额外卡组召唤圣物。
反应窗口 (Response window) :: 发动、召唤或攻击宣言之后，另一位决斗者可以用速攻效果回应的时机。回应会开启连锁。
返回手牌 (Return to hand) :: 把卡从场上移回持有者的手牌。见“弹回”。
翻开展示 (Reveal) :: 把卡展示给双方——检索到的卡、随机手牌、卡组顶。
Rite :: 降临体红色的法术子类。每张仪式指名一只要牺牲的怪兽和一只要召唤的降临体——以此方式召唤的降临体永久留场。
检索 (Search) :: 从卡组把特定的卡拿到手牌。之后洗切卡组。
赛季 (Season) :: 一个月的排位。每月开始新赛季。
盖放 (Set) :: 把卡以里侧打出：怪兽以守备表示（消耗你的通常召唤），或法术留待之后发动。
洗入卡组 (Shuffle into the Deck) :: 把卡放回持有者的卡组并洗切。与返回手牌不同——这张卡会有一段时间够不着。
特殊召唤 (Special Summon) :: 任何非通常召唤的召唤——由效果，或由怪兽自身的条件（“当……时你可以从手牌特殊召唤此卡”）。自身条件每回合每卡名一次。
法术 (Spell) :: 从手牌花费法力打出、用完进墓地的卡。通常法术在你的主要阶段；速攻法术在任何反应窗口。
独立 (Standalone) :: 自成一体、与卡上其他效果无关的灌能效果。
准备阶段 (Standby Phase) :: 回合的第二阶段：“在你的准备阶段”的效果、代价与维护。
召唤条件 (Summon requirement) :: 圣物登场前的要求：场上、墓地或生命值的状态——加上法力，有时还有祭献。
目标 (Target) :: 效果瞄准的卡，在发动时选择。“不会成为目标”正是免疫这一点。
衍生物 (Token) :: 由效果创造而非来自卡组的怪兽。它不进墓地，而是直接消散。
祭献 (Tribute) :: 把你控制的怪兽送入墓地作为代价——用于2级或3级的通常召唤，或用于圣物。有些圣物会从对手场上收取祭献。
回合玩家 (Turn player) :: 当前回合的决斗者。
种族 (Type) :: 见“怪兽种族”。
直到本回合结束 (Until the end of the turn) :: 在结束阶段撤销的临时变化。永久变化则保持到卡离场。
白板 (Vanilla) :: 没有效果的怪兽。有些卡正是支援它们。
区域 (Zone) :: 桌上的格位。每位决斗者有五个怪兽区域、三个法术区域和两个神器区域。把卡放在哪里由你决定。
法术区域 (Spell Zone) :: 盖放的法术等待发动的三个格位之一。每位决斗者三个。
相邻 (Adjacent) :: 同一侧紧挨某张卡左右两格的怪兽。“对相邻怪兽”的光环与保护只看这两格——中间空开就不再生效。
对面 (Facing) :: 正对某张卡的对手怪兽（1号位对1号位，依此类推）。“对面的怪兽”类效果在对面区域为空时不命中任何东西。
移动 (Move) :: 把怪兽移到己方另一个空怪兽区域的效果。移动会改变相邻与对面的关系——有些卡会在移动时触发。
掷硬币 (Coin flip) :: 效果掷一枚硬币：正面或反面，概率相同。卡片写明每种结果的后果——反面从不是“什么都不发生”，而是赌局的另一面。结果的目标在掷完后选择。
正面 (Heads) :: 硬币的好的一面——通常如此。
反面 (Tails) :: 硬币的另一面。有些卡可以重掷，或把反面当作正面。
LP费用 (LP cost) :: 作为代价支付的生命值（“支付1点法力和1000 LP：……”）。支付后必须至少剩1点LP。与伤害不同：有卡能让LP费用免费，但没有卡能让伤害免费。
法力债 (Mana debt) :: “你的下个回合少N点法力。”债务在那个回合开始时收取；每有1点无法偿还，改为失去1500 LP。
留置 (Lien) :: 怪兽上带数额的标记，显示为LIEN徽章。在其控制者的每个准备阶段，控制者支付等量法力，否则怪兽被破坏。留置可以被提高，控制权变更时仍然保留。
控制权互换 (Swap control) :: 两只怪兽永久换边——不像“获得控制权直到回合结束”那样在结束阶段归还。你收到的那只本回合不能攻击。
盗猎 (Poach) :: 从另一方玩家的墓地把怪兽特殊召唤到你自己的场上。被盗猎的怪兽离场时被放逐。
贯穿 (Piercing) :: 贯穿攻击者攻击守备力更低的守备表示怪兽时，差值照样作为战斗伤害结算。
每场决斗一次 (Once per Duel) :: 硬性限制：整场决斗中每位玩家每卡名只能用一次——第二份同名卡也不能重置它。
不能被通常召唤 (Cannot be Normal Summoned) :: 该怪兽只能靠自身的特殊召唤条件或其他效果登场——永远不能通常召唤或盖放。
不能被祭献 (Cannot be Tributed) :: 该怪兽不能作为通常召唤或圣物的祭献。想让对手留着的“礼物”正合适。
法术税 (Spell tax) :: 公会关税表侧在场时，双方的每张法术都要多支付1点法力——包括原本免费的。
攻击限制 (Attack limit) :: 决斗者守则表侧在场时，每位决斗者每个战斗阶段只能宣言一次攻击。
战斗伤害翻倍 (Double battle damage) :: 豪赌生效期间，双方受到的所有战斗伤害翻倍——对手的战斗阶段和你自己的都算。
宣言种类 (Declare a type) :: 在翻开卡之前宣言怪兽、法术或神器；相符的留下，其余进墓地。
减半直接攻击 (Direct attack, halved) :: 可以越过对手的怪兽直接攻击、但只造成一半攻击力伤害的怪兽。
Vessel :: 被标记为容器的怪兽——印在卡上。每次供奉的祭品中至少要有1只容器。通常为低等级；每个系列2只。
Zone Seal :: 被砌死的怪兽区域：封印期间无法向其中召唤、放置或移动。以砖墙叠加显示；有的封印会到期，有的绑定于其来源卡。
