# 决斗目标
两位决斗者，两座秘库，一张桌子。对手的生命值归0的那一刻——或者对手必须从空卡组抽卡而无牌可抽时——你就获胜了。这本手册的其余部分讲的都是如何走到那一步：可支配的法力、可召唤的怪兽、可用来回应的法术，以及封定胜局的圣物。

如果你从未玩过这类卡牌游戏，请先读「桌面」「你的回合」和「战斗」。其余的等用到时再看也不迟。

# 桌面
每位决斗者拥有一排五个怪兽区域、三个放置盖放法术的法术区域、两个神器区域、卡组、墓地、放逐区和额外卡组。你的手牌位于屏幕下方；对手手牌的背面显示在上方。你的玩家卡——你的英雄——立于你这一排的左侧；生命值和法力显示在右侧的面板上。

[img:plate|上方是生命值，下方是法力。数值变化时会跳动。]

生命值：初始8000（部分英雄略多或略少）。伤害——无论来自战斗还是效果——会减少它；治疗使其回升。没有上限。

法力：在你每个回合开始时补满。第一个回合3点，之后每回合多1点，至多10点。未用完的法力在回合结束时消失，除非卡片另有说明。法力用于法术、灌能效果、英雄效果和圣物召唤——普通的怪兽效果不需要法力。

手牌上限：8张。你的回合结束时超过上限的话，丢到只剩8张。

[img:phases|阶段条。亮起的一格就是决斗当前所在的阶段。]

# 你的回合
一个回合按固定顺序经过五个阶段：

- 抽卡阶段——抽1张卡。先攻方在其第一个回合跳过（先攻起手5张，后攻6张）。
- 准备阶段——写着“在你的准备阶段”的效果现在发生。各种代价与维护在此支付。
- 主要阶段——回合的核心。召唤或盖放一只怪兽、打出法术和神器、发动起动效果、改变表示形式、召唤圣物。顺序随意，只要法力和规则允许。
- 战斗阶段——用你的表侧攻击表示怪兽发起攻击。先攻方在其第一个回合没有战斗阶段。
- 结束阶段——“在你的结束阶段”的效果、手牌上限，然后回合交给对手。

你可以随时用阶段按钮结束主要阶段或战斗阶段；游戏永远不会强迫你攻击。

[img:hand|你的手牌。当前可以打出的卡会有描边；拖到桌上或点击查看选项。]

# 卡片
每张卡属于四种类别之一——外加英雄。

怪兽拥有等级（1到3）、属性（火、水、风、地、光、暗）、种族（龙、人类、野兽、机械、天使、恶魔、神话、动物……）以及攻击力/守备力。它们进攻、防守，而且大多带有效果。

法术从手牌花费法力打出，用完进入墓地。通常法术在你的主要阶段打出；速攻法术还可以作为回应打出——在对手的回合、连锁的中途、攻击宣言之时。任何法术也都可以先以里侧盖放、之后再发动。

神器留在桌上。有的装备给怪兽（为装备者提供攻守加成和效果），有的是场地神器，有的安放在你的玩家格位上。神器区域可放两张；盖放的法术在三个法术区域中等待。

[img:artifacts|神器区域里的两张玩家神器。除非有东西移除它们，否则一直留在场上。]

圣物住在你的额外卡组里。每张都把自己的召唤条件印在卡上——充实的墓地、三只怪兽、命悬一线的英雄——外加法力价格，有时还有祭献。条件达成后，你就可以在主要阶段召唤它。

玩家卡是你的英雄。它决定你的初始生命值，并提供一个英雄效果：2点法力，每回合一次，随时可用。英雄不能被攻击或破坏。

[img:card|怪兽卡的构造：顶部是名称和等级纹章，插画下方是属性和种族，底部是攻击力和守备力，文本框里是效果。]

[img:effectbox|决斗中点击任意卡片，左侧的查看面板会列出它的效果——先是费用徽章，然后是发动时机。]

# 召唤
通常召唤——每回合一次，从手牌，在你的主要阶段。1级怪兽免费登场。2级需要1个祭献，3级需要2个：先把相应数量的你控制的怪兽送入墓地。你也可以不以表侧召唤，而是把怪兽以里侧守备表示盖放——这同样消耗你的通常召唤。

特殊召唤——一切非通常召唤的召唤。由卡片完成：“从你的墓地特殊召唤1只怪兽”“当……时你可以从手牌特殊召唤此卡”。特殊召唤不消耗你的通常召唤，每回合也没有次数限制——唯一的例外是，每个卡名自己的“你可以特殊召唤此卡”条件每回合只能用一次。

圣物召唤——从额外卡组，在你的主要阶段，只要其印刷的条件达成。支付法力，献上它要求的祭献（有些会从对手场上收取），选择一个区域。

每只被召唤的怪兽都要选定区域和表示形式。表侧攻击表示以攻击力作战；守备表示以守备力抵挡、不造成伤害。里侧的怪兽总是守备表示；在翻开之前，没人知道它是什么。

[img:zones-attack|两只攻击表示的怪兽和一只盖放的怪兽：里侧，只能看到卡背。]

[img:zones-defense|守备表示横过来放——由守备力面对攻击者。]

# 战斗
在你的战斗阶段，每只表侧攻击表示怪兽可以攻击一次。点它，再点目标——或者点对手的英雄发动直接攻击。只有对手不控制任何怪兽时才能直接攻击。怪兽被召唤的当回合就可以正常攻击，除非卡片另有说明。

- 攻击「攻击表示」：攻击力高者获胜，败者被破坏，差值作为伤害由败者的控制者承受。攻击力相同：两者都被破坏，无人受伤。
- 攻击「守备表示」：你的攻击力对上它的守备力。攻击力更高则破坏防守方——不造成伤害。攻击力更低：对方怪兽存活，而你承受差值伤害。相同：什么都不发生。
- 攻击里侧怪兽会先将其翻开；如果它有翻转效果，效果此时触发。
- 直接攻击：全额攻击力作为伤害。

表示形式每只怪兽每回合可在你的主要阶段改变一次——但召唤当回合不行，攻击之后也不行。把里侧怪兽翻开转为攻击表示也算作它的这次表示切换。

# 效果
卡片文本会告诉你效果何时发生、代价是什么。措辞是固定的，学一次就够了：

- 召唤时——此卡被召唤时。自动触发；由你选择目标。
- 起动——你在自己的主要阶段发动（“每回合一次：……”）。
- 速攻——只要反应窗口开着就能发动，对手的回合也可以。
- 被动——只要卡以表侧在场就一直生效。无需发动，没有费用。
- 准备/结束阶段——在你回合的对应阶段发生。
- 翻转——里侧的卡被翻开时，无论是你自己翻的还是被攻击翻的。
- 手牌/墓地——有些效果从手牌或墓地使用；牌堆里有能行动的卡时会发光。点击牌堆。
- 每回合一次——字面意思。有些效果是“每回合一次、以卡名为准”。

费用在前，效果在后：“支付2点法力：抽1张卡”意味着即使抽卡被无效，法力也已经花掉了。如果一个效果此刻根本无法处理——没有合法目标、召唤没有空区域——那么它根本无法发动。

[img:activation|效果发动时，卡片和文本会走到前台，双方决斗者都能看清正在发生什么。]

# 灌能效果
许多卡带有灌能效果：总是需要法力的强化版本。分两种：

- 连动（“改为支付2点法力：……”）升级它上面的那条效果。每回合只能用普通版或灌能版其中之一，不能都用。
- 独立是一条自成一体的能力。与卡上其他内容并行不悖。

读卡时看法力徽章：蓝底带数字=要花这么多，绿色“无费”=免费。

[img:cardtext|卡片文本面板逐条列明：费用徽章、效果名称、发动时机、是否每回合一次。]

# 连锁与回应
每当卡片被发动、怪兽被召唤或攻击被宣言时，对手会得到一个反应窗口——对方行动时你也一样。用速攻效果回应就构成连锁：连锁1、连锁2、连锁3……当无人再追加时，连锁从最后一个开始倒序处理。

当第二个效果回应第一个时，屏幕上方会落下连锁追踪器，按顺序列出各个连锁——你的是青色，对方的是红色。追加时显示“连锁构筑中”，处理时显示“连锁处理中”，从最后一个开始。

连锁处理期间不能发动任何新效果——连本该触发的效果也要等。它们等连锁结束后再触发。被无效的卡佩戴紫色NEG徽章，其效果到回合结束前都不起作用；它仍然尝试行动时，游戏会明说，然后继续。

[img:log|右侧的决斗记录按顺序保存每一次发动、支付和结果。拿不准时，回头读一读。]

左下角的反应开关可以关闭自动询问：对手的行动不再为你暂停，只有你自己的触发仍会询问。手里没有回应手段时很好用。

[img:reactions|反应开：游戏会暂停并提供回应机会。关：只有你自己的触发会询问。]

# 牌堆
墓地——被破坏、用过和丢弃的卡的去处。许多效果从这里带回卡片或清点其中的卡。点击牌堆可以翻看。

放逐区——第二个墓地。被放逐的卡脱离决斗，除非有卡把它们专门带回来。有些圣物会清点它们。

卡组——背面朝上、已洗切。“检索”效果从中找卡；“磨切”把顶端的卡送入墓地。抽空不要紧——需要抽卡却抽不了才是败北。

额外卡组——你的圣物，至多20张。它们永远不会被抽到；它们等待自己的条件。

[img:piles|卡组、墓地、放逐区和额外卡组排在你半场的边缘。数字显示里面有多少张。]

# 卡组编辑器
一副卡组有40到80张卡，每张卡至多3份，外加一位英雄和额外卡组中至多20张圣物。禁限表可能进一步限制特定卡的份数——限制印在卡片上，保存时强制生效。

你只能用自己拥有的卡组建卡组。每张卡还有四种卡面工艺——普通、亮面、彩虹、静电——你放进卡组的那份的工艺，就是上桌时的样子。开不出的卡可以用尘埃合成；分解多余的卡能拿回尘埃。

# 去哪里玩
- 单人——各种脾气的机器人。适合熟悉卡组。
- 对战——赚金币和段位的线上队列、凭码进入的私人房间，以及观战直播决斗的WATCH。
- 挑战——高塔：十五层，十五位塔守，每层首通送卡包。
- 轮抽——从全新卡池组建卡组，用抽到的牌一路攀登。
- 商店——卡包、英雄宝库和外观；「统计」告诉你什么卡在赢。

每场线上对局无论胜负平都有金币。段位分推动你穿过十枚封印、各五个小段；一个赛季为期一个月。

# 最后一句
卡片文本大于本手册。当卡片所写与规则不同，以卡片为准——秘库里满是例外，隔壁的「术语表」解释了它们用到的每一个词。
