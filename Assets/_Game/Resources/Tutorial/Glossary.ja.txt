発動 (Activate) :: 魔法、アーティファクト、効果を使うこと。コストは発動時に払い、効果はその後に処理される — 誰かが応じればチェーンリンクとして処理される。
カード群 (Archetype) :: 一緒に動くよう作られた、名前を持つカードの一族。たいてい名前の頭を共有する（«潮縛り»、«大悪魔»）。カード群を名指しするサポートカードもそのカード群に属する。デッキ工房はカード群で絞り込める。
アーティファクト (Artifact) :: テーブルに残るカード。モンスターアーティファクトはモンスター1体に装着され（装着者にATK／DEFボーナスと効果）、フィールドアーティファクトはテーブル全体に、プレイヤーアーティファクトは自分の英雄に働く。アーティファクトゾーンはデュエリストごとに2つ。
ATK (ATK) :: 攻撃力。モンスターが攻撃する時や、攻撃表示で攻撃された時に使う。効果で一時的に（「ターン終了時まで」）または永続的に変わる。
攻撃表示 (Attack Position) :: 縦向きの表側表示モンスター。攻撃でき、ATKで戦う。戦闘に負けるとコントローラーがその差分をダメージとして受ける。
属性 (Attribute) :: モンスターの元素：炎、水、風、地、光、闇。属性を求める効果や召喚条件がある。
除外 (Banish) :: カードを除外の山 — 第二の墓地 — へ移すこと。除外されたカードは、特別に戻すカードがない限りデュエルの外だ。
除外の山 (Banishment) :: 除外されたカードの山。ここから戻す効果や、ここを数える聖遺物がある。
バンリスト (Banlist) :: デッキに2枚、1枚、または0枚に制限されたカードのリスト。デッキ保存時に適用され、制限数はデッキ工房のタイルに表示される。
戦闘ダメージ (Battle damage) :: 戦闘によるダメージ：ATKの差分か、直接攻撃のATK全部。効果ダメージとは別物 — 片方だけ防ぐカードがある。
Battle Phase (Battle Phase) :: ターンの第四のフェイズ。表側攻撃表示モンスターはそれぞれ1回攻撃できる。先攻のデュエリストは最初のターンにBattle Phaseがない。
表示形式 (Battle position) :: 攻撃か守備か。モンスターごとに1ターンに1度、Main Phaseに変更する — 召喚されたターンと攻撃した後は不可。
バウンス (Bounce) :: 「手札に戻す」の俗称。バウンスされたモンスターはフィールドで得たものをすべて失う。
カードの種類 (Card type) :: モンスター、魔法、アーティファクト、聖遺物、プレイヤーカード。どれかを宣言させる効果がある。
チェーン (Chain) :: 発動の積み重ね。効果が別の効果に応じるとリンク1、2、3…となり、誰もリンクを足さなくなったらチェーンは逆順に — 最後のリンクから — 処理される。チェーン処理中は何も新たに発動できない。
チャージ (Charged) :: 残り火のメカニズム：このターンより前にセットされた魔法は、自分のStandby Phaseの間により強いチャージ版を発動できる。
コイン (Coins) :: デュエルで稼ぐ通貨。パックと着せ替えを買える。
永続効果 (Continuous effect) :: 「永続」の項を参照。
コントロール (Control) :: カードが誰のフィールドにあるか。モンスターのコントロールを奪う効果はあるが、持ち主は変わらない — フィールドを離れると持ち主の墓地や手札に戻る。
コスト (Cost) :: 発動のために払うもの：マナ、手札を捨てる、生贄、除外。コストは効果が後で無効になっても返ってこない。
カウンター (Counter) :: 効果がカードの上に置く目印。死のカウンターは数字付きのドクロで表示され、積み重なると何が起きるかはカードに書いてある。
連結型 (Coupled) :: 上の効果を強化するINFUSED効果（「その代わりにマナ2を払う：…」）。1ターンには通常版か連結型のどちらか一方しか使えない。
生成 (Craft) :: 砂を持っていないカードに変えること。余った1枚を分解すると砂が返ってくる。
死のカウンター (Death counter) :: End Phaseごとに増えるカウンター。カードに記された上限に達すると、そのカードは破壊される。数字付きのドクロで表示。
デッキ (Deck) :: 自分のメインの山。40～80枚、同じカードは最大3枚。裏向きにシャッフルされ、一番上からドローする。
守備表示 (Defense Position) :: 横向きに寝かせたモンスター。攻撃できず、DEFで持ちこたえ、戦闘ダメージを与えない。裏側表示モンスターは常に守備表示。
DEF (DEF) :: 守備力。守備表示で攻撃された時に使う。攻撃側のATKの方が低ければ、攻撃側のコントローラーがその差分を受ける。
破壊 (Destroy) :: 戦闘や効果でカードをフィールドから墓地へ送ること。「破壊されない」はまさにこれだけを防ぐ — 除外、バウンス、生贄は防げない。
直接攻撃 (Direct attack) :: モンスターではなく相手の英雄への攻撃。相手がモンスターをコントロールしていない間だけ可能。攻撃側のATK全部をダメージとして与える。
捨てる (Discard) :: カードを手札から墓地へ送ること。「ランダム」は無作為に、それ以外は捨てるプレイヤーが選ぶ。
ドラフト (Draft) :: 新しいカードプールからデッキを組み、引き当てたもので登っていくモード。
Draw Phase (Draw Phase) :: ターンの最初のフェイズ：カードを1枚ドローする。先攻のデュエリストは最初のターンにこれを飛ばす。
砂 (Dust) :: 分解されたカードが変わるもの。カードの生成に使う。
効果ダメージ (Effect damage) :: 戦闘ではなくカードの効果が与えるダメージ（「800ダメージを与える」）。片方だけ防ぐカードがある。
End Phase (End Phase) :: ターンの最後のフェイズ：「自分のEnd Phaseの間」の効果、手札枚数の制限、そしてターンが渡る。
装着 (Equip) :: モンスターアーティファクトをモンスター — 装着者 — に付けること。装着者がフィールドを離れると、アーティファクトは墓地へ行く。
エクストラデッキ (Extra Deck) :: 自分の聖遺物たち、最大20枚。ドローされることはなく、それぞれカードに記された召喚条件を待つ。
裏側表示 (Face-down) :: 伏せて出されたカード。裏側表示モンスターは常に守備表示。裏側の魔法はセットされたもので、後で発動できる。
フィールド (Field) :: テーブル：両デュエリストのすべてのゾーン。「フィールドに」とは、モンスターゾーンかアーティファクトゾーンに表でも裏でもあるということ。
フィールドアーティファクト (Field Artifact) :: アーティファクトゾーンに置かれ、モンスター1体ではなくテーブル全体に働くアーティファクト。
仕上げ (Finish) :: カードの1枚の見た目：ノーマル、光沢、レインボー、スタティック。純粋に見た目だけ。デッキに入れた1枚の仕上げがテーブルに出る。
不発 (Fizzle) :: 効果の処理時に、できることが何も残っていない状態 — 対象が消えた、ゾーンが埋まった。効果は何もせず、コストは払ったまま。
リバース (Flip) :: 裏側表示モンスターが表側になること — 自分で（攻撃表示へ）、攻撃されて、または効果で。この時リバース効果が発動する。
墓地 (Graveyard) :: 破壊されたカード、使ったカード、捨てたカードの行き先。ここからカードを戻したり、中身を数えたりする効果が多い。山をクリックすれば中を見られる。
手札 (Hand) :: 持っているカード。自分ターン終了時に最大8枚。
手札枚数の制限 (Hand limit) :: 8枚。End Phaseにそれより多ければ、8枚になるまで捨てる。
英雄 (Hero) :: 「プレイヤーカード」の項を参照。
起動効果 (Ignition effect) :: 自分のMain Phaseに自分から発動する効果（「1ターンに1度：…」）。
幻影トークン (Illusion Token) :: ガスライトのカード群が相手フィールドに置く0/0のトークン。ゾーンを1つ埋め、破壊してアドバンテージに変えられる。
INFUSED (Infused) :: カードに載った、常にマナのかかるより強い効果。連結型（上の効果の強化版）か独立型（それ自体の能力）のどちらか。
レベル (Level) :: 1、2、3。紋章に表示される。レベル2は通常召喚に生贄1体、レベル3は2体が必要。聖遺物はレベル3。
ライフポイント (Life Points) :: 自分の体力。開始時は8000（英雄によって異なることがある）。0になったらデュエルに敗北する。
LP (LP) :: ライフポイントの略。
Main Phase (Main Phase) :: ターンの第三のフェイズ：召喚、魔法とアーティファクトのプレイ、起動効果の発動、表示形式の変更、聖遺物の召喚。
マナ (Mana) :: 魔法、INFUSED効果、英雄効果、聖遺物召喚のための資源。自分のターンごとに補充される：最初は3、ターンごとに1ずつ増えて最大10。使わなかったマナは、カードが別に言わない限り消える。
削る (Mill) :: デッキの一番上からカードを墓地へ送ること。自分のデッキでも相手のでも。
モンスター (Monster) :: 戦うカード。レベル、属性、タイプ、ATK、DEF — そしてたいてい効果を持つ。
モンスターアーティファクト (Monster Artifact) :: モンスター1体に装着されるアーティファクト。
モンスタータイプ (Monster Type) :: ドラゴン、人間、獣、機械、天使、悪魔、神話、動物… タイプを気にする効果がある。
無効 (Negate) :: カードの効果を切ってしまうこと。無効になったカードはターン終了時まで紫のNEGバッジを付け、何かしようとしても何も起きない。
通常召喚 (Normal Summon) :: 自分のMain Phaseに手札からモンスターを出すこと、1ターンに1度。レベル1は無料、レベル2は生贄1体、レベル3は2体。モンスターを裏側でセットするのもこの回数を使う。
1ターンに1度 (Once per turn) :: その効果はターンごとに1回使える。カード名につき1ターンに1度のものもある — 3枚あっても1回を分け合う。
持ち主 (Owner) :: カードがどのデッキから来たか。コントロールが変わっていても、カードは持ち主の手札、デッキ、墓地に戻る。
永続 (Passive) :: カードがフィールドに表側である間、ただ効いている効果。発動もコストもチェーンリンクもない。
フェイズ (Phase) :: ターンを構成する五つの段階の一つ：Draw、Standby、Main、Battle、End。
プレイヤーカード (Player Card) :: 自分の英雄。開始ライフポイントを定め、マナ2で1ターンに1度使える英雄効果をくれる。攻撃も破壊もされない。
表示形式の変更 (Position change) :: モンスターを攻撃表示と守備表示の間で切り替えること。モンスターごとに1ターンに1度、自分のMain Phaseに。
速攻魔法 (Quick Spell) :: レスポンスとして発動できる魔法 — 相手ターンに、チェーンの途中に、攻撃が宣言された時に。自分のMain Phaseでも使える。
ランク (Rank) :: 五段階ずつの十個の封印。ランクデュエルはランクポイントで上下させ、シーズンは一か月続く。
レアリティ (Rarity) :: コモン、アンコモン、レア、レジェンダリー — パックから出る頻度。カードの強さとは無関係。
リアクション切替 (Reactions toggle) :: デュエル画面左下のスイッチ。オフにすると、相手の行動へのレスポンスの提案が止まる。自分のトリガーは引き続き尋ねてくる。
聖遺物 (Reliquary) :: エクストラデッキのボスモンスター。召喚条件、マナの代価、生贄はカードに記されている。他のモンスターと同じくモンスターゾーンを占める。
聖遺物召喚 (Reliquary Summon) :: 条件が満たされたら、自分のMain Phaseにエクストラデッキから聖遺物を呼び出すこと。
レスポンスウィンドウ (Response window) :: 発動、召喚、攻撃宣言の直後に、もう一方のデュエリストが速攻効果で応じられる瞬間。応じるとチェーンが始まる。
手札に戻す (Return to hand) :: カードをフィールドから持ち主の手札へ移すこと。「バウンス」の項を参照。
公開 (Reveal) :: カードを両プレイヤーに見せること — サーチしたカード、ランダムな手札、デッキの一番上。
サーチ (Search) :: デッキから特定のカードを手札に加えること。その後デッキはシャッフルされる。
シーズン (Season) :: ランク戦の一か月。毎月新しいシーズンが始まる。
セット (Set) :: カードを裏側で出すこと：モンスターは守備表示で（通常召喚の回数を使う）、魔法は後で発動するために。
デッキに加えてシャッフル (Shuffle into the Deck) :: カードを持ち主のデッキに戻してシャッフルすること。手札に戻すのとは違い — そのカードはしばらく手が届かない。
特殊召喚 (Special Summon) :: 通常召喚ではないすべての召喚 — 効果によるもの、またはモンスター自身の条件によるもの（「…なら手札から特殊召喚できる」）。自身の条件はカード名につき1ターンに1度。
魔法 (Spell) :: マナを払って手札からプレイし、その後墓地へ行くカード。通常魔法は自分のMain Phaseに。速攻魔法はレスポンスウィンドウが開くたびに。
独立型 (Standalone) :: カードの他の効果と無関係な、それ自体の能力であるINFUSED効果。
Standby Phase (Standby Phase) :: ターンの第二のフェイズ：「自分のStandby Phaseの間」の効果、通行料と維持費。
召喚条件 (Summon requirement) :: 聖遺物が呼ばれる前に求めるもの：フィールド、墓地、ライフポイントの状態 — それにマナと、時には生贄。
対象 (Target) :: 効果が狙うカード。発動時に選ぶ。「対象にならない」はまさにこれに対する免疫。
トークン (Token) :: デッキから引かれたのではなく、効果が生み出したモンスター。墓地へ行く代わりに消える。
生贄 (Tribute) :: 代価として自分がコントロールするモンスターを墓地へ送ること — レベル2・3の通常召喚や聖遺物のため。相手フィールドから生贄を取る聖遺物もある。
ターンプレイヤー (Turn player) :: 今ターンを進めているデュエリスト。
タイプ (Type) :: 「モンスタータイプ」の項を参照。
ターン終了時まで (Until the end of the turn) :: End Phaseに元に戻る一時的な変化。永続的な変化はカードがフィールドを離れるまで残る。
バニラ (Vanilla) :: 効果を持たないモンスター。まさにそういうモンスターを支えるカードもある。
ゾーン (Zone) :: テーブルの枠。デュエリストごとにモンスターゾーン5つ、魔法ゾーン3つ、アーティファクトゾーン2つ。どこに置くかは自分の選択。
魔法ゾーン (Spell Zone) :: セットされた魔法が発動を待ちながら裏側で置かれる三つの枠の一つ。デュエリストごとに3つ。
隣接 (Adjacent) :: 同じ側で、カードのすぐ左右のゾーンにいるモンスター。「隣接モンスター」のためのオーラや保護は、まさにそのモンスターに働く — 間が空くともう働かない。
向かい合う (Facing) :: カードの真向かいのゾーンにいる相手モンスター（1番ゾーンは1番ゾーンと向かい合う）。「このカードと向かい合うモンスター」を撃つ効果は、そのゾーンが空なら何も撃てない。
移動 (Move) :: モンスターを同じ側の別の空いているモンスターゾーンへ移す効果。移動すると隣接と向かい合いが変わる — 移動時に発動するカードもある。
コイントス (Coin flip) :: 効果がコインを投げる：表か裏、確率は同じ。それぞれの結果が何をするかはカードに書いてある — 裏が「何も起きない」であることはなく、賭けのもう一面だ。結果ごとの対象は投げた後に選ぶ。
表 (Heads) :: コイントスの良い面 — たいていは。
裏 (Tails) :: コイントスのもう一面。投げ直させたり、裏を表として扱ったりするカードもある。
LPコスト (LP cost) :: 代価として払うライフポイント（「マナ1とLP1000を払う：…」）。払うには最低1LPが残っていなければならない。ダメージとは違う：LPコストを無料にするカードはあるが、ダメージを無料にするカードはない。
マナの借金 (Mana debt) :: 「次の自分ターンの間マナがN減る。」借金はそのターンの始めに取り立てられる。払えなかったマナ1につき、代わりにLPを1500失う。
抵当 (Lien) :: モンスターに付く額付きの目印。LIENバッジで表示される。コントローラーの各Standby Phaseごとに、その分のマナを払わなければそのモンスターは破壊される。抵当は上げられ、コントロールが変わっても残る。
コントロールの入れ替え (Swap control) :: モンスター2体が永続的に陣営を替えること — 「ターン終了時までコントロールを得る」と違い、End Phaseに戻らない。受け取った方はそのターン攻撃できない。
密漁 (Poach) :: もう一方のプレイヤーの墓地からモンスターを自分のフィールドに特殊召喚すること。密漁されたモンスターはフィールドを離れると除外される。
貫通 (Piercing) :: 貫通を持つ攻撃側が、DEFの低い守備表示モンスターを攻撃すると、それでもその差分を戦闘ダメージとして与える。
デュエル中に1度 (Once per Duel) :: 強い制限：プレイヤーとカード名につき、デュエル全体で1回しか使えない — 2枚目でもリセットされない。
通常召喚不可 (Cannot be Normal Summoned) :: そのモンスターは自身の特殊召喚条件か他の効果でしかフィールドに出ない — 通常召喚やセットでは決して出ない。
生贄不可 (Cannot be Tributed) :: そのモンスターは通常召喚や聖遺物の生贄として払えない。相手に持ち続けてほしい贈り物の時に役立つ。
魔法税 (Spell tax) :: ギルド関税が表側である間、すべての魔法は両デュエリストにとってマナ1多くかかる — 無料だったはずのものでも。
攻撃制限 (Attack limit) :: デュエリストの掟が表側である間、各デュエリストはBattle Phaseごとに攻撃を1回しか宣言できない。
戦闘ダメージ2倍 (Double battle damage) :: 高額の賭け金が働いている間、どちらのデュエリストへの戦闘ダメージも2倍になる — 相手のBattle Phaseも自分のも。
種類の宣言 (Declare a type) :: カードを公開する前に、モンスター、魔法、アーティファクトのいずれかを宣言する。一致したものは手に入り、残りは墓地へ行く。
直接攻撃（半減） (Direct attack (halved)) :: 相手のモンスターを素通りして直接攻撃できるが、その方法ではATKの半分しかダメージを与えないモンスター。
