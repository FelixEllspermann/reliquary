발동 (Activate) :: 마법, 아티팩트, 효과를 사용하는 것. 코스트는 발동 시에 지불하고, 효과는 그 후에 처리된다 — 누군가 응수하면 체인 링크로 처리된다.
카드군 (Archetype) :: 함께 움직이도록 만들어진, 이름이 붙은 카드 집단. 보통 이름 앞부분을 공유한다 («조수결박», «대악마»). 카드군을 지정하는 지원 카드도 그 카드군에 속한다. 덱 공방은 카드군으로 필터링할 수 있다.
아티팩트 (Artifact) :: 테이블에 남는 카드. 몬스터 아티팩트는 몬스터 1장에 장착되고 (장착자에게 ATK/DEF 보너스와 효과), 필드 아티팩트는 테이블 전체에, 플레이어 아티팩트는 자신의 영웅에게 작용한다. 듀얼리스트마다 아티팩트 존은 2칸.
ATK (ATK) :: 공격력. 몬스터가 공격하거나 공격 표시로 공격받을 때 사용한다. 효과로 일시적으로 («턴 종료 시까지») 또는 영구히 변한다.
공격 표시 (Attack Position) :: 세로로 세워진 앞면 표시 몬스터. 공격할 수 있고 ATK로 싸운다. 전투에서 지면 그 차이만큼 컨트롤러가 데미지를 받는다.
속성 (Attribute) :: 몬스터의 원소: 화염, 물, 바람, 땅, 빛, 어둠. 일부 효과와 소환 조건이 속성을 요구한다.
제외 (Banish) :: 카드를 제외 더미 — 두 번째 묘지 — 로 보내는 것. 제외된 카드는 특별히 되돌리는 카드가 없는 한 듀얼에서 빠진 것이다.
제외 더미 (Banishment) :: 제외된 카드가 쌓이는 더미. 일부 효과는 여기서 되돌리고, 일부 성유물은 여기 있는 카드를 센다.
밴리스트 (Banlist) :: 덱당 2장, 1장 또는 0장으로 제한된 카드 목록. 덱을 저장할 때 적용되며, 제한 수는 덱 공방의 카드 타일에 표시된다.
전투 데미지 (Battle damage) :: 전투에서 나오는 데미지: ATK 차이, 또는 직접 공격의 ATK 전부. 효과 데미지와는 다르다 — 어떤 카드는 한쪽만 막는다.
Battle Phase (Battle Phase) :: 턴의 네 번째 페이즈. 앞면 공격 표시 몬스터는 각각 1번 공격할 수 있다. 선공 듀얼리스트는 맨 첫 턴에 Battle Phase가 없다.
표시 형식 (Battle position) :: 공격 또는 수비. 몬스터마다 1턴에 1번, Main Phase에 변경한다 — 소환된 턴과 공격한 후에는 불가.
바운스 (Bounce) :: «패로 되돌리기»의 속어. 바운스된 몬스터는 필드에서 얻은 것을 전부 잃는다.
카드 종류 (Card type) :: 몬스터, 마법, 아티팩트, 성유물, 플레이어 카드. 일부 효과는 이 중 하나를 선언하게 한다.
체인 (Chain) :: 발동의 쌓임. 효과가 다른 효과에 응수하면 링크 1, 2, 3…이 되고, 아무도 링크를 더하지 않으면 체인은 역순으로 — 마지막 링크부터 — 처리된다. 체인 처리 중에는 아무것도 새로 발동할 수 없다.
충전 (Charged) :: 잔불의 메커니즘: 이번 턴 이전에 세트된 마법은 자신의 Standby Phase 동안 더 강한 충전 버전을 발동할 수 있다.
코인 (Coins) :: 듀얼로 버는 화폐. 팩과 꾸미기를 산다.
지속 효과 (Continuous effect) :: «지속» 항목 참조.
컨트롤 (Control) :: 카드가 누구의 필드에 있는가. 일부 효과는 몬스터의 컨트롤을 빼앗지만 소유자는 바뀌지 않는다 — 필드를 벗어나면 소유자의 묘지나 패로 돌아간다.
코스트 (Cost) :: 발동을 위해 지불하는 것: 마나, 버리기, 제물, 제외. 코스트는 효과가 나중에 무효가 되어도 돌려받지 못한다.
카운터 (Counter) :: 효과가 카드 위에 놓는 표식. 죽음 카운터는 숫자 달린 해골로 표시되며, 쌓이면 무슨 일이 생기는지는 카드에 적혀 있다.
결합형 (Coupled) :: 위의 효과를 강화하는 INFUSED 효과 («그 대신 마나 2 지불: …»). 한 턴에는 일반 버전이나 결합형 중 하나만 사용한다.
제작 (Craft) :: 가루를 없는 카드로 바꾸는 것. 남는 사본을 분해하면 가루를 돌려받는다.
죽음 카운터 (Death counter) :: End Phase마다 쌓이는 카운터. 카드에 적힌 한계에 도달하면 그 카드는 파괴된다. 숫자 달린 해골로 표시된다.
덱 (Deck) :: 자신의 메인 더미. 40~80장, 같은 카드는 최대 3장. 뒷면으로 섞여 있고 맨 위에서 드로우한다.
수비 표시 (Defense Position) :: 옆으로 눕힌 몬스터. 공격할 수 없고 DEF로 버티며 전투 데미지를 주지 않는다. 뒷면 표시 몬스터는 항상 수비 표시다.
DEF (DEF) :: 수비력. 수비 표시로 공격받을 때 사용한다. 공격자의 ATK가 더 낮으면 공격자의 컨트롤러가 그 차이를 데미지로 받는다.
파괴 (Destroy) :: 전투나 효과로 카드를 필드에서 묘지로 보내는 것. «파괴되지 않는다»는 정확히 이것만 막는다 — 제외, 바운스, 제물은 막지 못한다.
직접 공격 (Direct attack) :: 몬스터 대신 상대 영웅을 공격하는 것. 상대가 몬스터를 컨트롤하지 않는 동안에만 가능하다. 공격자의 ATK 전부를 데미지로 준다.
버리기 (Discard) :: 카드를 패에서 묘지로 보내는 것. «무작위» 버리기는 무작위로, 그 외에는 버리는 플레이어가 고른다.
드래프트 (Draft) :: 새 카드 풀에서 덱을 짜서, 뽑은 카드로 올라가는 모드.
Draw Phase (Draw Phase) :: 턴의 첫 페이즈: 카드를 1장 드로우한다. 선공 듀얼리스트는 맨 첫 턴에 이를 건너뛴다.
가루 (Dust) :: 분해된 카드가 변하는 것. 카드 제작에 쓴다.
효과 데미지 (Effect damage) :: 전투가 아니라 카드 효과가 주는 데미지 («800 데미지를 준다»). 어떤 카드는 한쪽만 막는다.
End Phase (End Phase) :: 턴의 마지막 페이즈: «자신의 End Phase 동안» 효과, 패 매수 제한, 그리고 턴이 넘어간다.
장착 (Equip) :: 몬스터 아티팩트를 몬스터 — 장착자 — 에게 붙이는 것. 장착자가 필드를 벗어나면 아티팩트는 묘지로 간다.
엑스트라 덱 (Extra Deck) :: 자신의 성유물들, 최대 20장. 드로우되지 않으며, 각자 카드에 적힌 소환 조건을 기다린다.
뒷면 표시 (Face-down) :: 숨겨서 낸 카드. 뒷면 표시 몬스터는 항상 수비 표시이고, 뒷면 마법은 세트된 것으로 나중에 발동할 수 있다.
필드 (Field) :: 테이블: 양쪽 듀얼리스트의 모든 존. «필드에»는 몬스터 존이나 아티팩트 존에 앞면이든 뒷면이든 있다는 뜻이다.
필드 아티팩트 (Field Artifact) :: 아티팩트 존에 놓여 몬스터 1장이 아니라 테이블 전체에 작용하는 아티팩트.
마감 (Finish) :: 카드 사본의 외관: 일반, 광택, 무지개, 스태틱. 순전히 장식이며, 덱에 넣은 사본의 마감이 테이블에 나온다.
불발 처리 (Fizzle) :: 효과가 처리될 때 할 수 있는 것이 남아 있지 않은 상황 — 대상이 떠났거나 존이 차 있거나. 효과는 아무것도 하지 않고, 코스트는 그대로 지불된 채다.
리버스 (Flip) :: 뒷면 표시 몬스터가 앞면이 되는 것 — 스스로 (공격 표시로), 공격당해서, 또는 효과로. 이때 리버스 효과가 발동한다.
묘지 (Graveyard) :: 파괴된 카드, 사용한 카드, 버린 카드가 가는 곳. 많은 효과가 여기서 카드를 되살리거나 안에 있는 것을 센다. 더미를 클릭하면 살펴볼 수 있다.
패 (Hand) :: 손에 든 카드. 자신 턴 종료 시 최대 8장.
패 매수 제한 (Hand limit) :: 8장. End Phase에 그보다 많으면 8장이 될 때까지 버린다.
영웅 (Hero) :: «플레이어 카드» 항목 참조.
기동 효과 (Ignition effect) :: 자신의 Main Phase에 스스로 발동하는 효과 («1턴에 1번: …»).
환영 토큰 (Illusion Token) :: 가스라이트 카드군이 상대 필드에 놓는 0/0 토큰. 존을 하나 차지하며, 파괴해서 이득으로 바꿀 수 있다.
INFUSED (Infused) :: 카드에 실린, 항상 마나가 드는 더 강한 효과. 결합형 (위 효과의 강화판)이거나 독립형 (자체 능력)이다.
레벨 (Level) :: 1, 2, 3. 문장(紋章)에 표시된다. 레벨 2는 일반 소환에 제물 1개, 레벨 3은 2개가 필요하다. 성유물은 레벨 3이다.
라이프 포인트 (Life Points) :: 자신의 체력. 시작은 8000 (영웅에 따라 다를 수 있다). 0이 되면 듀얼에서 패배한다.
LP (LP) :: 라이프 포인트의 줄임말.
Main Phase (Main Phase) :: 턴의 세 번째 페이즈: 소환, 마법과 아티팩트 플레이, 기동 효과 발동, 표시 형식 변경, 성유물 소환.
마나 (Mana) :: 마법, INFUSED 효과, 영웅 효과, 성유물 소환의 자원. 자신 턴마다 다시 찬다: 처음엔 3, 턴마다 1씩 늘어 최대 10. 쓰지 않은 마나는 카드가 달리 말하지 않는 한 사라진다.
갈기 (Mill) :: 덱 맨 위에서 카드를 묘지로 보내는 것. 자신 덱이든 상대 덱이든.
몬스터 (Monster) :: 싸우는 카드. 레벨, 속성, 타입, ATK, DEF — 그리고 대부분 효과를 가진다.
몬스터 아티팩트 (Monster Artifact) :: 몬스터 1장에 장착되는 아티팩트.
몬스터 타입 (Monster Type) :: 드래곤, 인간, 야수, 기계, 천사, 악마, 신화, 동물… 일부 효과가 타입을 따진다.
무효 (Negate) :: 카드의 효과를 꺼 버리는 것. 무효가 된 카드는 턴 종료 시까지 보라색 NEG 배지를 달며, 뭔가 하려 해도 아무 일도 일어나지 않는다.
일반 소환 (Normal Summon) :: 자신의 Main Phase에 패에서 몬스터를 내는 것, 1턴에 1번. 레벨 1은 무료, 레벨 2는 제물 1개, 레벨 3은 2개. 몬스터를 뒷면으로 세트하는 것도 이 횟수를 쓴다.
1턴에 1번 (Once per turn) :: 그 효과를 턴마다 1번 쓸 수 있다. 일부는 카드 이름당 1턴에 1번이다 — 3장이 있어도 1번을 나눠 쓴다.
소유자 (Owner) :: 카드가 어느 덱에서 왔는가. 컨트롤이 바뀌었어도 카드는 소유자의 패, 덱, 묘지로 돌아간다.
지속 (Passive) :: 카드가 필드에 앞면으로 있는 동안 그냥 켜져 있는 효과. 발동도, 코스트도, 체인 링크도 없다.
페이즈 (Phase) :: 턴을 이루는 다섯 단계 중 하나: Draw, Standby, Main, Battle, End.
플레이어 카드 (Player Card) :: 자신의 영웅. 시작 라이프 포인트를 정하고, 마나 2로 1턴에 1번 쓰는 영웅 효과를 준다. 공격받지도 파괴되지도 않는다.
표시 형식 변경 (Position change) :: 몬스터를 공격 표시와 수비 표시 사이에서 바꾸는 것. 몬스터마다 1턴에 1번, 자신의 Main Phase에.
속공 마법 (Quick Spell) :: 리스폰스로 발동할 수 있는 마법 — 상대 턴에, 체인 도중에, 공격이 선언되었을 때. 자신의 Main Phase에도 쓸 수 있다.
랭크 (Rank) :: 다섯 단계씩 나뉜 열 개의 봉인. 랭크 듀얼은 랭크 포인트로 오르내리게 하며, 시즌은 한 달 동안 이어진다.
레어도 (Rarity) :: 커먼, 언커먼, 레어, 레전더리 — 팩에서 나오는 빈도. 카드의 강함과는 무관하다.
리액션 스위치 (Reactions toggle) :: 듀얼 화면 왼쪽 아래의 스위치. 끄면 상대 행동에 대한 리스폰스 제안이 멈춘다. 자신의 트리거는 계속 물어본다.
성유물 (Reliquary) :: 엑스트라 덱의 보스 몬스터. 소환 조건, 마나 가격, 제물이 카드에 적혀 있다. 다른 몬스터처럼 몬스터 존을 차지한다.
성유물 소환 (Reliquary Summon) :: 조건이 충족되면 자신의 Main Phase에 엑스트라 덱에서 성유물을 불러내는 것.
리스폰스 타이밍 (Response window) :: 발동, 소환, 공격 선언 직후에 상대 듀얼리스트가 속공 효과로 응수할 수 있는 순간. 응수하면 체인이 시작된다.
패로 되돌리기 (Return to hand) :: 카드를 필드에서 소유자의 패로 옮기는 것. «바운스» 항목 참조.
공개 (Reveal) :: 카드를 양쪽 플레이어에게 보여주는 것 — 서치한 카드, 무작위 패, 덱 맨 위.
서치 (Search) :: 덱에서 특정 카드를 패에 넣는 것. 그 후 덱을 섞는다.
시즌 (Season) :: 랭크전의 한 달. 매달 새 시즌이 시작된다.
세트 (Set) :: 카드를 뒷면으로 내는 것: 몬스터는 수비 표시로 (일반 소환 횟수를 쓴다), 마법은 나중에 발동하도록.
덱에 넣고 섞기 (Shuffle into the Deck) :: 카드를 소유자의 덱에 되돌리고 섞는 것. 패로 되돌리기와 달리 — 그 카드는 당분간 손이 닿지 않는다.
특수 소환 (Special Summon) :: 일반 소환이 아닌 모든 소환 — 효과로, 또는 몬스터 자신의 조건으로 («…라면 이 카드를 패에서 특수 소환할 수 있다»). 자체 조건은 카드 이름당 1턴에 1번이다.
마법 (Spell) :: 마나를 내고 패에서 플레이한 뒤 묘지로 가는 카드. 일반 마법은 자신의 Main Phase에, 속공 마법은 리스폰스 타이밍이 열릴 때마다.
독립형 (Standalone) :: 카드의 다른 효과와 무관한, 자체 능력인 INFUSED 효과.
Standby Phase (Standby Phase) :: 턴의 두 번째 페이즈: «자신의 Standby Phase 동안» 효과, 통행료와 유지비.
소환 조건 (Summon requirement) :: 성유물이 불려 나오기 전에 요구하는 것: 필드, 묘지, 라이프 포인트의 상태 — 그리고 마나와 때로는 제물.
대상 (Target) :: 효과가 겨누는 카드. 발동 시에 고른다. «대상이 되지 않는다»는 정확히 이것에 면역이 된다는 뜻이다.
토큰 (Token) :: 덱에서 나온 것이 아니라 효과가 만들어낸 몬스터. 묘지로 가는 대신 사라진다.
제물 (Tribute) :: 대가로 자신이 컨트롤하는 몬스터를 묘지로 보내는 것 — 레벨 2·3의 일반 소환이나 성유물을 위해. 일부 성유물은 상대 필드에서 제물을 가져간다.
턴 플레이어 (Turn player) :: 지금 턴을 진행 중인 듀얼리스트.
타입 (Type) :: «몬스터 타입» 항목 참조.
턴 종료 시까지 (Until the end of the turn) :: End Phase에 원래대로 돌아가는 일시적 변화. 영구적 변화는 카드가 필드를 벗어날 때까지 남는다.
바닐라 (Vanilla) :: 효과가 없는 몬스터. 바로 이런 몬스터를 지원하는 카드도 있다.
존 (Zone) :: 테이블의 칸. 듀얼리스트마다 몬스터 존 5칸, 마법 존 3칸, 아티팩트 존 2칸. 어디에 놓을지는 자신의 선택이다.
마법 존 (Spell Zone) :: 세트된 마법이 발동을 기다리며 뒷면으로 놓이는 세 칸 중 하나. 듀얼리스트마다 3칸.
인접 (Adjacent) :: 같은 편에서 카드 바로 왼쪽과 오른쪽 존에 있는 몬스터들. «인접 몬스터»를 위한 오라와 보호는 정확히 그 몬스터들에게 적용된다 — 사이가 비면 더 이상 적용되지 않는다.
마주 보기 (Facing) :: 카드 바로 맞은편 존에 있는 상대 몬스터 (1번 존은 1번 존과 마주 본다). «이 카드와 마주 보는 몬스터»를 치는 효과는 그 존이 비어 있으면 아무것도 치지 못한다.
이동 (Move) :: 몬스터를 같은 편의 다른 빈 몬스터 존으로 옮기는 효과. 이동하면 인접과 마주 보기가 달라진다 — 이동할 때 발동하는 카드도 있다.
코인 토스 (Coin flip) :: 효과가 코인을 던진다: 앞면 또는 뒷면, 확률은 같다. 각 결과가 무엇을 하는지는 카드에 적혀 있다 — 뒷면은 결코 «아무 일도 없음»이 아니라 내기의 반대편이다. 결과에 따른 대상은 던진 후에 고른다.
앞면 (Heads) :: 코인 토스의 좋은 쪽 — 대체로.
뒷면 (Tails) :: 코인 토스의 다른 쪽. 다시 던지게 하거나 뒷면을 앞면으로 치는 카드도 있다.
LP 코스트 (LP cost) :: 대가로 지불하는 라이프 포인트 («마나 1과 LP 1000 지불: …»). 지불하려면 LP가 최소 1은 남아야 한다. 데미지와는 다르다: LP 코스트를 무료로 만드는 카드는 있어도, 데미지를 무료로 만드는 카드는 없다.
마나 빚 (Mana debt) :: «다음 자신 턴 동안 마나가 N 줄어든다.» 빚은 그 턴이 시작될 때 걷힌다. 갚지 못한 마나 1마다 대신 LP를 1500 잃는다.
담보 (Lien) :: 몬스터에 붙는 액수 달린 표식. LIEN 배지로 표시된다. 컨트롤러의 각 Standby Phase마다 그만큼의 마나를 지불하지 않으면 그 몬스터는 파괴된다. 담보는 올릴 수 있고, 컨트롤이 바뀌어도 남는다.
컨트롤 맞바꾸기 (Swap control) :: 몬스터 2장이 영구히 편을 바꾸는 것 — «턴 종료 시까지 컨트롤을 얻는다»와 달리 End Phase에 돌아가지 않는다. 받은 몬스터는 그 턴에 공격할 수 없다.
밀렵 (Poach) :: 다른 플레이어의 묘지에서 몬스터를 자신의 필드에 특수 소환하는 것. 밀렵된 몬스터는 필드를 벗어나면 제외된다.
관통 (Piercing) :: 관통 능력을 가진 공격자가 DEF가 더 낮은 수비 표시 몬스터를 공격하면, 그래도 그 차이만큼 전투 데미지를 준다.
듀얼 중 1번 (Once per Duel) :: 강한 제한: 플레이어와 카드 이름당 듀얼 전체에서 1번만 쓸 수 있다 — 두 번째 사본으로도 초기화되지 않는다.
일반 소환 불가 (Cannot be Normal Summoned) :: 그 몬스터는 자신의 특수 소환 조건이나 다른 효과로만 필드에 나온다 — 일반 소환이나 세트로는 결코 나오지 않는다.
제물 불가 (Cannot be Tributed) :: 그 몬스터는 일반 소환이나 성유물의 제물로 바칠 수 없다. 상대가 계속 갖고 있어야 하는 선물일 때 유용하다.
마법세 (Spell tax) :: 길드 관세가 앞면으로 있는 동안, 모든 마법은 양쪽 듀얼리스트에게 마나 1이 더 든다 — 무료였을 마법까지도.
공격 제한 (Attack limit) :: 듀얼리스트의 법도가 앞면으로 있는 동안, 각 듀얼리스트는 Battle Phase마다 공격을 1번만 선언할 수 있다.
전투 데미지 2배 (Double battle damage) :: 높은 판돈이 작동하는 동안, 어느 듀얼리스트가 받는 전투 데미지든 2배가 된다 — 상대의 Battle Phase도, 자신의 것도.
종류 선언 (Declare a type) :: 카드를 공개하기 전에 몬스터, 마법, 아티팩트 중 하나를 선언한다. 일치하는 것은 갖고, 나머지는 묘지로 간다.
직접 공격 (반감) (Direct attack (halved)) :: 상대 몬스터를 지나쳐 직접 공격할 수 있지만, 그 방식으로는 ATK의 절반만 데미지를 주는 몬스터.
